# Om Mishra — Personal Portfolio

A responsive, single-page personal portfolio built with semantic HTML, CSS, and vanilla JavaScript. No build step, framework, API key, or paid service is required.

## Run it

1. Download `om-portfolio.zip` and extract it.
2. Open the `om-portfolio` folder in VS Code.
3. Open `index.html` in a browser. For the best local development workflow, use VS Code Live Server or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Included

- Hero section with animated code-editor illustration
- Sticky navbar, mobile menu, desktop quick-navigation rail, and active-section highlighting
- About and education journey
- Filterable skills cards with honest learning-status labels
- Five project cards with accessible detail dialogs
- Current-focus roadmap
- Dark/light theme toggle
- Responsive layout, reduced-motion support, keyboard focus states, SEO metadata, SVG favicon, and dynamic copyright year
- GitHub profile links: https://github.com/ommishra5331-hue

## Free deployment

### GitHub Pages
1. Create a GitHub repository, e.g. `om-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `favicon.svg` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; its URL will appear in Pages settings.

### Netlify
1. Visit https://app.netlify.com/drop.
2. Drag the extracted `om-portfolio` folder into the page.
3. Netlify will provide a published URL.
